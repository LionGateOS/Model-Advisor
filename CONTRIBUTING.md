# Contributing to LionGateOS Model Advisor

Contributions are welcome.

This project is still in early public development, so please open an issue or discussion before beginning a large change.

## Good Contribution Areas

Examples include:

- hardware detection and compatibility;
- AI runtime support;
- model metadata;
- quantization guidance;
- benchmark definitions;
- recommendation logic;
- tests and validators;
- UI and accessibility;
- themes and translations;
- documentation.

## Pull Requests

Please keep pull requests focused on one clear purpose.

Before submitting:

- explain what problem the change solves;
- include tests or verification when behavior changes;
- avoid unrelated changes;
- do not include API keys, credentials, personal information, private machine data, or proprietary WorkRunner material.

Large architectural changes should be discussed before implementation.

## Public / Private Boundary

This repository is the public Model Advisor project.

Do not copy private LionGateOS WorkRunner implementation, execution policy, approval machinery, proprietary routing logic, private evidence, credentials, or machine-specific private information into this repository.
